Architecture

The 5-Phase AI Pipeline

Every resume passes through a rigorous multi-stage evaluation process before a final weighted score is produced.

Phase 01
📄
Parse & Sanitize
PyPDF2 extracts text. spaCy NER redacts PERSON, ORG, GPE and DATE entities for blind screening.
Phase 02
⚡
GitHub TCFE
Temporal Commit Flow Engine with 3-pronged anti-cheat: rate limiting, impact filter & LLM semantic scoring.
Phase 03
🧠
Semantic Embedding
HuggingFace MiniLM-L6-v2 chunks & embeds the resume into ChromaDB with cosine similarity indexing.
Phase 04
⚖️
LLM Evaluation
Llama 3.2 scores candidates: Semantic (40) + PoW Depth (30) + Experience (15) + Keywords (15) = 100.
Phase 05
🕸️
Knowledge Graph
NetworkX generates a D3.js force-directed skill topology showing matches, gaps, and extra competencies.

Workflow

Three Steps to Insight

1
Upload PDF Resume
Drop a PDF resume. The system extracts text, auto-redacts PII, detects GitHub URLs, and fetches live TCFE commit metrics.
2
Enter Job Description
Paste the JD. The resume is chunked into ChromaDB vectors and the LLM retrieves the most semantically relevant excerpts.
3
Get AI Report
Receive a full report: weighted final score, XAI explanation, skill gap analysis, and an interactive D3 knowledge graph.

Scoring Model

Objective, Weighted Evaluation

TalentGraph AI uses a four-component scoring rubric enforced by the LLM, then applies a Temporal Velocity multiplier when recent GitHub activity is detected.

⚡ Proof-of-Work Depth 30 pts
📅 Experience Depth 15 pts
🔑 Keyword Alignment 15 pts
🚀 Temporal Velocity Bonus +Burst ×10%
